三套布局并排，改 widget.css 一处，三个同时变。 尺寸与透明度直接拖滑块 —— 它们就是挂件窗口将来的真实属性。

A · 紧凑型信息密度优先

一屏尽量多。任务多、想扫一眼全貌时用。

B · 宽松型可读性优先

字号 +1.5px、留白加大。任务少、更在意看清每一条。

C · 卡住优先按紧急度重排

把「卡住了」抽成独立分区置顶 —— 它才是唯一需要你动手的。

怎么迭代
  1. 改 widget.css（配色/间距/字号都在 :root 变量里）→ 刷新浏览器
  2. 改 widget.js（渲染逻辑）→ 刷新浏览器
  3. 数据变了：跑 python refresh-data.py → 刷新浏览器
  4. 连不上看板时自动用内置样例数据，界面照样完整，不会白屏

尺寸与透明度的实现口径：宽度写在挂件根元素的 --w， 字号系数 --scale = (w/320)^0.45（开平方根而非等比 —— 等比的话 760px 时字号到 28px，满屏是字、信息反而更少）， 透明度 --bg-alpha 只作用于背景与卡片面，文字保持不透明； 宽度 ≥470px 自动并排两列：放大的收益落在"看得更多"而不是"字更大"。

改样式时请保留：配色只用 :root 变量（要和看板同源）；语义色不可改 （停滞=warn、完成=ok、失败=bad、进行中=accent）。
