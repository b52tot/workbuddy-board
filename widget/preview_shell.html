下面是真实挂件的 DOM 与样式（@SRC@），只换了主题变量。 每套都放了一块假桌面当背景，方便判断透明度的真实观感。
右上角 = 窗口控制（Windows 惯例） — 收起为迷你条　✕ 关闭（隐藏到托盘，悬停变红）
原来这里混着 ↗ 打开浏览器 和 ⤓ 最小化到托盘， ⤓ 与 ✕ 语义重复，已去掉。
右下角 = 应用动作 ↗ 在浏览器打开完整看板　⚙ 设置
原来 ✕ 摆在这里 —— Windows 用户找关闭一律去右上角，放右下角反直觉。
设置面板 宽度 → 字号（窗口高度自适应内容）
布局（紧凑/宽松/卡住优先）→ 主题（四选一）
透明度 → 作用于整个前端，不再只改背景色。
