# 挂件原型 · 迭代说明

> 目的：**改完立刻看到效果**，不用编译、不用打包、不用起服务。

---

## 一分钟上手

双击 `index.html` 即可。三套布局并排，面板上有四组控制：

| 控制 | 作用 |
|---|---|
| **状态** | 展开 / 详情 / 收起 / 空 / 连不上 |
| **数据** | 真实看板（从 8791 拉）/ 代码开发示例（演示用，非真实任务） |
| **宽度** | 300–760px，**≥470px 自动并排两列** |
| **透明度** | 35%–100%（背景透明，文字保持清晰） |

> **为什么要「代码开发示例」**：真实看板里目前只有下载类任务，
> 看不出挂件在代码开发 / 其他项目里够不够用。这份演示数据刻意覆盖了
> 开发任务的几种形状：有多步骤进展的、被外部依赖卡住的、无进度的研究型任务、
> 以及已完成但耗时很长的。**它标注为「演示数据」，不会被当成真实任务。**

## 尺寸与透明度是怎么实现的

这两个是**挂件窗口的真实属性**，不是原型的装饰 —— 拖滑块看到的就是将来的行为。

### 尺寸

| 量 | 做法 | 为什么 |
|---|---|---|
| 宽度 | 写 `--w` 到挂件根元素 | 窗口可拖边缩放 |
| 字号 | `--scale = (w/320)^0.45` | **开平方根而不是等比** —— 等比的话 760px 时字号到 28px，满屏都是字，信息反而更少 |
| 两列 | `w ≥ 470` 时加 `.wide`，列组变 grid 两栏 | **放大的收益落在「看得更多」而不是「字更大」** |
| 间距 | `calc(Npx * var(--scale))` | 字号变大而内边距不变，会挤成一团 |

实测：320→×1.00 · 520→×1.24 · 760→×1.45（且两列）。

### 透明度

| 做法 | 为什么 |
|---|---|
| `--bg-alpha` 只作用于**背景与卡片面**，文字保持不透明 | 挂件常驻桌面，挡住后面的东西比看不清更烦人；但字一旦也变淡就彻底没法读 |
| 外壳 + 卡片面 + 标签 + 按钮**一起透** | 只透外壳会出现"外壳透明、里面实心"的割裂感 |
| 工作台用棋盘格底垫着 | 否则看不出"透" |

范围 35%–100%（低于 35% 基本看不清字，没意义）。

## 改什么 → 看什么

| 想改 | 改哪个文件 | 生效方式 |
|---|---|---|
| 配色 / 间距 / 字号 / 圆角 | **`widget.css`** | 刷新浏览器 |
| 卡片里显示什么、怎么排 | **`widget.js`** | 刷新浏览器 |
| 换真实数据 | 跑 `python refresh-data.py` | 刷新浏览器 |
| 工作台本身（三列并排那些） | `index.html` | 刷新浏览器 |

**改 `widget.css` 一处，三套布局同时变** —— 这是对比迭代最快的路径。

## 文件职责

```
index.html        迭代工作台（三套并排 + 状态切换）—— 只看不改也行
widget.css        ★ 样式，配色/间距/字号全在这（前端设计主战场）
widget.js         渲染逻辑，数据 → HTML
data.js           数据（由 refresh-data.py 生成，别手工改）
refresh-data.py   从看板拉真实数据 → data.js
prototype.html    最初的单方案原型（保留作对照，可删）
```

## 三套布局的区别

| | 定位 | 差异 |
|---|---|---|
| **A 紧凑型** | 信息密度优先 | 字号 12.5 / 卡片高 8px10px / 一屏尽量多 |
| **B 宽松型** | 可读性优先 | 字号 14 / 卡片高 12px13px / 留白多 |
| **C 卡住优先** | 按紧急度重排 | **把"卡住了"抽成独立分区置顶**，其余列照常 |

三套共用同一份 `widget.css` 与 `widget.js`，只在 `body` 的 class 上分叉
（`.theme-a` / `.theme-b` / `.theme-c`）—— 所以改一处三处生效。

## 数据从哪来

```
看板服务 127.0.0.1:8791
        │  refresh-data.py 拉一次（快照）
        ▼
     data.js  ──[<script src>]──▶  原型页面
```

**为什么是快照而不是实时请求**：原型要能**双击直接打开**（`file://`），
而 `file://` 下跨域请求 8791 会被浏览器拦掉。用 `<script>` 注入数据不受同源策略限制。
代价是数据要手动刷 —— 对"看视觉"这个用途够用。

**连不上看板时自动用内置样例数据**，界面照样完整、不白屏。
页面顶栏会标注是 `● 实时看板` 还是 `● 样例数据`，不会把样例当真数据看。

## 改样式时必须保留的约束

1. **配色只用 `:root` 里的变量** —— 挂件要和看板同源（上一版被否的原因之一就是"相去甚远"）
2. **语义色不可改**：停滞=`--warn`、完成=`--ok`、失败=`--bad`、进行中=`--accent`
3. **宽度恒为 320px** —— 任何元素都不许把它撑出横向滚动
4. **标题 2 行截断、说明 1 行截断** —— 保住"看得出是哪一个"，同时不撑高卡片
5. **五个状态都要照顾到**，尤其「空」和「连不上」必须长得**明显不同**
