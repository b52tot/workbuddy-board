常驻桌面的小窗口，实时显示看板上的四列任务（待办 / 进行中 / 阻塞 / 已完成）。 单文件 exe，不需要装 Python，也不需要另外部署服务 —— 看板后端和 MCP 端点都打包在里面了。

1怎么用

  1. 下载 BoardWidget.exe，放到任意目录（桌面就行）。
  2. 双击运行。首次启动会自己拉起看板服务，窗口右上角是 —（收起）和 ✕（收进托盘）。
  3. 系统托盘图标右键可以显示 / 隐藏挂件；右下角 ⚙ 里可换主题、调字号、接入 MCP。

2首次运行会被拦一下

这个 exe 没有做代码签名，Windows SmartScreen 会弹「Windows 已保护你的电脑」。 点「更多信息」→「仍要运行」即可。杀毒软件也可能对 UPX 压缩壳敏感而报一次警， 同样属于误报。
