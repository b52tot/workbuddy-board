# 给设计师的作图需求

## 1. 用途与尺寸

- 朋友圈单图推广（会先显示成方形缩略图，点开看全图）
- 尺寸：**1080 × 1440**（3:4 竖版）或 1080 × 1080
- 关键信息请放在**上半部分** —— 缩略图会裁掉下半截

## 2. 图上必须出现的文案

**主标题（最大字号）**
> 把看板，钉在桌面上

**副标题 / 引导语**
> 四列任务常驻桌面角落，不用切窗口，也不用点开浏览器

**四个卖点（建议带图标或色点）**

| # | 卖点 | 补充 |
|---|---|---|
| 1 | 单文件 exe，双击即用 | 不装 Python，也不用另外部署服务 |
| 2 | 每 2 秒同步 | agent 干到哪一步，看板自己就写上了 |
| 3 | 停滞任务自动标黄 | 一眼看出哪个卡住了 |
| 4 | 四套主题 · 字号可调 | 还能收成窄条贴在屏幕边上 |

**底部信息**
> 扫码下载
> board-widget-download.app.workbuddy.host
> Windows 10 / 11 · 64 位 · 14.0 MB · 绿色免安装

**产品名**
> WorkBuddy Board ｜ 桌面任务看板挂件 · 免安装单文件

## 3. 二维码

- 链接：`https://board-widget-download.app.workbuddy.host/`
- 建议白底圆角方块，放在右下或底部正中，尺寸占画布宽度 15% 以上（太小扫不出来）
- 二维码必须**清晰可扫**，不要叠在花纹或深色图上

## 4. 视觉方向

- **暗色底**（深褐 / 深灰），暖色强调。信息流里暗底亮字更跳
- 强调色：琥珀 `#F5A524`
- 主文字：`#F4EFE4`；次要文字：`#B3A992`
- 字体：微软雅黑 / 思源黑体，标题用粗体
- 产品外观可参考随附的界面截图（`主题_亚克力白.png`）
- 风格偏「工具感、干净」，不要花哨的 3D 渲染和夸张光效

## 5. 素材

- 界面截图：见随附文件
- 产品图标：一个圆角方块 + 四条竖杠（象征看板的四列），琥珀渐变底
- 一句话记忆点：**"把看板钉在桌面上"**

## 6. 交付

- PNG，1080×1440（或 1080×1080）
- 同时要一版**无二维码**的（万一二维码需要单独替换）
- 源文件（PSD / Figma / AI）保留
